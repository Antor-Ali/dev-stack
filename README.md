Project Name
Dev Stack – Technology Stack Explorer


A Little Description
Dev Stack is a modern and responsive web application that helps developers explore different technologies and build their ideal development stack. Users can view technology details, select technologies, and manage their selected stack easily.


Three Features
1- Technology Explorer
Users can explore different technologies with their icon, category, description, difficulty level, badge, and rating.

2- Your Stack Management
Users can add technologies to Your Stack, remove individual technologies, and remove all selected technologies at once. Duplicate technologies are prevented.

3- Responsive & Interactive UI
The website is fully responsive for desktop, tablet, and mobile devices, with a sticky navbar, mobile hamburger menu, loading state, and toast notifications for user actions.
